## Spacing Scale

Inherited from Phase 1 (8-point scale, all multiples of 4). No changes to base scale.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, flag badge spacing, chip gaps within filter bar |
| sm | 8px | Cell padding in segment table, intra-row gap, term row gap |
| md | 16px | Panel section padding, form field gap, glossary card padding |
| lg | 24px | Page section vertical gap, card padding |
| xl | 32px | Page content horizontal padding |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level vertical rhythm |

**Phase 2 exceptions (extend Phase 1 list):**
- Segment table row minimum height: 48px (source/target textarea min-height; accessible click target on flag icon)
- Segment textarea min-height: 48px; grows with content (no max-height enforced — react-virtuoso handles scroll at the list level)
- Filter chip height: 32px (compact — they live in a horizontal chip bar, not as primary CTAs)
- Glossary term inline row height: 44px (touch target minimum for edit/delete icon buttons)
- Keyboard shortcut panel: 320px max-width, 40px per shortcut row

## Interaction Contracts

### Segment Table

| State | Trigger | Visual |
|-------|---------|--------|
| Default | — | Rows alternate bg-white / bg-white (no zebra — clean paper feel). Separator: border-slate-100 |
| Hovered | `mouseenter` on row | bg-slate-50 on full row |
| Focused | keyboard `j/k` navigation | ring-1 ring-violet-200 on full row. Focus follows pointer. |
| Editing | click target cell or keyboard `e` | Textarea focus ring: ring-2 ring-violet-500. Source cell fades to opacity-70. |
| Flagged | segment has 1+ flags | Flag badges render in FlagCell. Row left border: 3px solid amber/violet/orange/red per most-severe flag. |
| Saving | PATCH in-flight | Textarea border changes to dashed ring-slate-400. "Saving…" 12px slate-400 text in TargetCell footer. |
| Saved | PATCH resolves OK | "Saved" 12px slate-400 text with `Check` icon, fades out after 1.5s. |
| Error | PATCH failed + rollback | Toast: "Could not save — edit restored." Textarea value rolls back to prior cached value. |
| Regenerating | POST /regenerate in-flight | RegenerateButton shows spinner. TargetCell shows skeleton (2 lines). |
| Regenerated | POST resolves | New `translated_text` renders. If `edited_text` exists, "Discard edit" button appears below new translation. |

### Filter Chips

| State | Trigger | Behavior |
|-------|---------|----------|
| All (default) | page load | All segments visible. `All` chip is active violet. |
| Flag filter active | click flag chip | List filters to segments with that flag_type. Active chip: violet-500. Other chips: inactive. Segment count in chip: `(n)` live count. |
| Empty filter result | all segments flagged-clear for selected type | Empty state in table: "No segments with this flag type." — no icon, centered text. |

### Keyboard Shortcuts

All shortcuts active when focus is inside the review page and NOT inside an `<input>` or `<textarea>` (except `e` and `r` which target the current focused segment).

| Key | Action |
|-----|--------|
| `j` | Move focus to next segment |
| `k` | Move focus to previous segment |
| `n` | Move focus to next flagged segment (cycles through active filter or all flags if filter = All) |
| `e` | Focus the target textarea of the currently focused segment row |
| `r` | Trigger regenerate on the currently focused segment (shows confirm popover if segment has `edited_text`) |
| `Escape` | Blur active textarea, return focus to row |
| `?` | Toggle keyboard shortcut help panel |

Shortcuts are discoverable via the `?` icon button in the filter bar. The help panel renders all shortcuts as a 2-column grid (key | action) with Label typography.

### UPLD-04 Glossary Picker

| State | Trigger | Visual |
|-------|---------|--------|
| Both languages selected, matching glossaries exist | `source_lang` and `target_lang` both have values | `GlossarySelect` renders with glossary options |
| Both languages selected, no matches | pair has no glossaries in DB | Glossary row shows: "No glossary for this pair — [create one ↗]" (link to `/glossaries`). No select rendered. |
| Either language not selected | source or target is unset | Glossary row hidden (display: none — do not show a disabled empty select) |
| Glossary selected | user picks from dropdown | Persisted as `glossary_id` on form state. Locked at submit. |
| Glossary cleared | user picks "None" option | `glossary_id = null` on submit |

### Glossary CRUD

| Action | Pattern | Confirmation |
|--------|---------|-------------|
| Create glossary | Dialog form → POST `/glossaries` | No confirm — creation is low-risk |
| Edit glossary name | Inline edit (click `Pencil` icon → name becomes input, `Check` to save) | No dialog — in-place |
| Delete glossary | Click trash icon → `DeleteGlossaryDialog` modal | Dialog with destructive confirm copy (see Copywriting) |
| Add term | Inline `TermAddRow` at bottom of terms table | No confirm |
| Edit term | Inline edit row on row click | No dialog — in-place |
| Delete term | Click `Trash2` icon in row → immediate DELETE | No dialog (terms are cheap to re-add; see Copywriting for toast) |
| Import CSV | File picker → POST `/glossaries/{id}/terms/import` | On success: "Imported N terms." toast. On parse error: destructive toast with row number and error. |

### Discard Edit (REV-04 nuance)

When a segment has `edited_text != null` and the user clicks "Regenerate":
- Show inline confirm popover (not dialog): "Regenerate will update the base translation but your edit will remain. Continue? [Regenerate] [Cancel]"
- On confirm: fire POST /regenerate. `edited_text` is NOT cleared. New `translated_text` renders with "Discard edit" button below it.
- "Discard edit" button: one click → clear `edited_text` to null → PATCH `/segments/{id}` with `{edited_text: null}` → TanStack optimistic update.

### Export (REV-05/06)

| State | Trigger | Visual |
|-------|---------|--------|
| Export idle | job in `done` or `needs_review` | "Export Document" button enabled, violet-500 fill |
| Export running | POST `/jobs/{id}/export` in-flight | Button disabled, spinner inline: "Exporting…" |
| Export done | 200 response with file URL | Browser download triggered. Button re-enables. Toast: "Export ready — downloading." |
| Export error | 4xx/5xx | Toast destructive: "Export failed — {error message}. Try again." |
