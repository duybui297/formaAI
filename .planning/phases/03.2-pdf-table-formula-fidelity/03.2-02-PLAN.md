PyMuPDF find_tables() API (verified via Context7):
```python
# page.find_tables() returns a TableFinder object
finder = page.find_tables()    # uses default strategy
tables = finder.tables         # list[Table]

# Table object
table = tables[0]
table.bbox         # (x0, y0, x1, y1) bounding box of the whole table
table.cells        # list of (x0, y0, x1, y1) tuples, one per cell (all rows)
table.header       # TableHeader (may be None)
table.row_count    # int
table.col_count    # int

# Iterating cells in row-major order:
for r in range(table.row_count):
    for c in range(table.col_count):
        cell_bbox = table.extract()[r][c]  # or use table.cells with index arithmetic
```

IMPORTANT: `table.cells` is a flat list of ALL cells in row-major order.
Length = row_count * col_count. Index of cell (r, c) = r * col_count + c.
Each element is a pymupdf.Rect (not a tuple) — use rect.x0, rect.y0, rect.x1, rect.y1.

Cell text extraction: use `page.get_textbox(cell_rect)` to get text within the cell bbox.
This avoids re-running get_text("dict") per cell; it clips to the cell rect directly.

PITFALL: Some cells may be None (merged cells in the PDF). Skip None cells.

Structural position for cell segments:
  "page.{N}.table.{T}.row.{R}.col.{C}"
  where T = table index on the page (0-based), R = row index, C = col index.

NON-table blocks:
  After extracting table regions, use the same existing block-cluster walk for
  blocks NOT covered by any table bbox. A block is "in a table" if its bbox
  intersects with any detected table's bbox. Filter these out of the non-table
  block walk to avoid double-emitting table content.

  Check: pymupdf.Rect(block["bbox"]).intersects(table.bbox) for each block.
  If intersects → skip in the non-table block walk (already handled by cell walk).

**Algorithm (insert BEFORE the existing `column_groups, is_degraded = cluster_columns(...)` call):**

```python
import re as _re  # already imported in Plan 01 additions; ensure top-level only

# --- Table cell extraction (CONTEXT.md: find_tables() cell walk) ---
table_block_bboxes: list[pymupdf.Rect] = []  # track table regions for later filtering

finder = page.find_tables()
for table_idx, table in enumerate(finder.tables):
    table_rect = pymupdf.Rect(table.bbox)
    table_block_bboxes.append(table_rect)

    for r in range(table.row_count):
        for c in range(table.col_count):
            cell_idx = r * table.col_count + c
            if cell_idx >= len(table.cells):
                continue
            cell = table.cells[cell_idx]
            if cell is None:
                continue  # merged cell — skip
            cell_rect = pymupdf.Rect(cell)
            # Get cell text — page.get_textbox clips to the rect
            raw = _nfc(page.get_textbox(cell_rect).strip())
            if not raw:
                continue
            pos = f"page.{page_num}.table.{table_idx}.row.{r}.col.{c}"
            segments.append(Segment.from_text(
                source_text=raw,
                structural_position=pos,
                seq_in_job=seq,
                kind="table_cell",
            ))
            seq += 1
```
