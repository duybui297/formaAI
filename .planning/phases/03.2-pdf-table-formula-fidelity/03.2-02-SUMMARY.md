# Phase 03.2 Plan 02: Table Cell Extraction via find_tables() Summary

**One-liner:** Added `page.find_tables()` cell walk to `extract_pdf_segments` emitting `Segment(kind='table_cell')` per cell with `structural_position="page.N.table.T.row.R.col.C"`, with bbox-intersection filtering to prevent double-emission of table content in the non-table block walk.

## What Was Implemented

### find_tables() Cell Walk (extractor.py)

Inserted a table detection phase at the start of the per-page loop, immediately after text block extraction and before the existing `cluster_columns` call:

1. **Table detection**: `page.find_tables()` returns a `TableFinder` with `.tables` list. Each `Table` has `.cells` (flat list of `pymupdf.Rect` in row-major order), `.row_count`, and `.col_count`.

2. **Cell iteration**: For each `(table_idx, table)`, iterates `r in range(row_count)` × `c in range(col_count)`. Cell index = `r * col_count + c`. Guards: `cell_idx >= len(table.cells)` and `cell is None` (merged cell) both skip.

3. **Cell text extraction**: `page.get_textbox(cell_rect).strip()` clips text to the cell rectangle. Empty cells (`raw == ""`) are skipped — no segment emitted.

4. **Segment emission**: `Segment.from_text(source_text=raw, structural_position=pos, seq_in_job=seq, kind="table_cell")` where `pos = "page.{N}.table.{T}.row.{R}.col.{C}"`.

### Non-Table Block Filter

After the table walk, blocks whose bbox intersects any detected table region are excluded from `non_table_blocks`:

```python
non_table_blocks = [
    b for b in text_blocks
    if not any(pymupdf.Rect(b["bbox"]).intersects(tr) for tr in table_block_bboxes)
]
```

This prevents double-emission of table content (T-03.2-02-3). The filtered list replaces `text_blocks` as input to `cluster_columns`. An early `continue` is added when `non_table_blocks` is empty (all blocks were table-covered).

### Exception Safety (T-03.2-02-1)

`find_tables()` is wrapped in `try/except Exception`. On exception:
- Warning logged via `logging.getLogger(__name__).warning()`
- `table_block_bboxes` reset to `[]`
- Full non-table walk proceeds with all `text_blocks` — no data loss

### Pages Without Tables

When `find_tables()` returns zero tables, `table_block_bboxes` is empty, `non_table_blocks == text_blocks`, and the code path is identical to pre-03.2.

## find_tables() API Surprises and Edge Cases

1. **`table.cells` is a flat list of `pymupdf.Rect`** — not a 2D array. The plan's interface documentation was accurate: index `r * col_count + c`. Each element is a `pymupdf.Rect` (not a tuple), so `pymupdf.Rect(cell)` wrapping is required for `get_textbox`.

2. **Synthetic PDF detection**: The drawn-grid synthetic fixture (`table_pdf`) is reliably detected by `find_tables()` in PyMuPDF 1.26.x. The 2×3 grid with full border lines produces a clean `TableFinder` result.

3. **`intersects()` with border blocks**: Text blocks that PyMuPDF places at table cell positions overlap with the table bbox. The `intersects()` filter correctly removes them, preventing double-emission of cell text as both `kind='table_cell'` (from cell walk) and `kind='text'` (from block walk).

4. **Empty `non_table_blocks`**: When all blocks on a page are inside tables, `non_table_blocks` is empty. The original code would pass an empty list to `cluster_columns` — harmless but wasteful. Added an `if not non_table_blocks: continue` guard.
