# Phase 03.2 Plan 01: Segment.kind Field and Math Font Passthrough Detection Summary

**One-liner:** Added `Segment.kind` field with `"text"` default and `_is_math_font()` predicate using AdvP/CMSY/CMR/STIX/MT prefix allowlist to detect math/symbol-font spans for passthrough emission.

## What Was Implemented

### Segment.kind Field (segment.py)

Added `kind: str = "text"` to the `Segment` dataclass after `run_group_size`. The default of `"text"` makes all existing DOCX/PPTX/PDF segments backward-compatible without any change to callers. `Segment.from_text()` already accepts `**kwargs`, so `Segment.from_text(..., kind="math_passthrough")` works immediately without classmethod changes.

Valid values: `"text"` | `"table_cell"` | `"math_passthrough"`.

### _is_math_font Predicate (extractor.py)

Implements a three-level detection strategy:

1. **Exact match set**: `{"Symbol", "ZapfDingbats", "Wingdings"}` — legacy symbol fonts
2. **Prefix match**: `("AdvP", "CMSY", "CMR", "STIX", "MathFont", "MT")` — math font families
3. **Keyword regex**: `/math|symbol|glyph/i` — catch-all for named math fonts

PSNAME subset prefix stripping handles fonts like `"ABCDEF+AdvP4C4E74"` → strips to `"AdvP4C4E74"` before prefix matching.

**Key exclusion:** `AdvTT*` is NOT in the math prefix list. These are body-text subsets carrying Latin/CJK glyphs in a custom encoding — they translate correctly with Noto fonts. Only `AdvP*` (math/symbol encoding) is flagged.

### Math-Passthrough Emission in extract_pdf_segments (extractor.py)

Modified the inner block-emission loop to check all non-empty spans in a block for math fonts before taking the normal translation path:

- If ANY non-empty span uses a math font → emit `Segment(kind="math_passthrough")` with raw joined text and `continue` (skips `spans_to_html`)
- Otherwise → existing `spans_to_html` path unchanged

The structural_position build was moved above the math-font check so it's available to both code paths.

## Font Allowlist / Denylist Decisions

| Font pattern | Classification | Reason |
|---|---|---|
| `AdvP*` | math_passthrough | Math/symbol encoding; glyphs outside Noto Unicode coverage |
| `AdvTT*` | text | Body-text subset; Latin/CJK glyphs; translates correctly |
| `CMSY*` | math_passthrough | TeX Computer Modern Symbol |
| `CMR*` | math_passthrough | TeX Computer Modern Roman (used in math mode) |
| `STIX*` | math_passthrough | STIX math font family |
| `MathFont*` | math_passthrough | Generic math font naming |
| `MT*` (prefix) | math_passthrough | MathType fonts (MT-Extra, MT-Symbol) |
| `MT` suffix (e.g. `Arial-BoldMT`) | text | Arial body font; MT suffix is not the same as MT prefix |
| `Symbol` | math_passthrough | Legacy symbol font (exact match) |
| `ZapfDingbats` | math_passthrough | Decorative glyphs (exact match) |
| `Wingdings` | math_passthrough | Decorative glyphs (exact match) |
| `Noto*`, `Helvetica*`, `Arial*`, etc. | text | Standard body fonts |
