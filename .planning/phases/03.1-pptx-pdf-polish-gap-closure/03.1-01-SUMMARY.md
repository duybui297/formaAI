# Phase 03.1 Plan 01: PPTX Auto-Height Guard and Per-Paragraph Font Helper Summary

Per-paragraph font budget helper and shape-height guard for `detect_pptx_overflow` — prevents false-positive auto-fit on auto-height PPTX shapes (UAT Gap 1, Test 3).

## What Was Built

`_paragraph_dominant_font_pt(paragraph) -> float` helper returns the maximum explicit run font size across a paragraph's runs, defaulting to 18pt when all runs inherit from theme. `detect_pptx_overflow` now accepts an optional `paragraph` arg and guards against auto-fit on shapes with `height == 0 EMU` (auto-height shapes that already reflow naturally). Both call sites (`_write_back_text_frame` and `_write_back_table`) pass `paragraph=para`.
