# Phase 03.1 Plan 02: PDF Image-Collision Rect Clipping Summary

## One-liner

Rect-vs-image collision detection with adaptive right/bottom edge clipping in PDF reassembler Pass 3, closing UAT Gap 2 (Test 6).

## What Was Built

Added `_clip_rect_away_from_images` helper to `reassembler.py` that shrinks a text block's insertion rect to avoid overwriting adjacent image blocks. Image block bboxes (type==1) are collected once per page at the start of the Pass 3 loop. For each active pair, the text rect is clipped before `insert_htmlbox` is called. If the clipped rect falls below minimum dimensions, an `image_collision` overflow flag is emitted and the insert is skipped (source text preserved visibly).

Pass 1 (add_redact_annot) continues to use the original unclipped rect — this ensures the source caption text is fully erased. Only Pass 3 uses the safe clipped rect.
