<objective>
Close UAT Gap 2 (Test 6): PDF caption overlapping image after translation.

Root cause: the reassembler inserts translated text into the original rect without
checking whether adjacent non-text content (images, graphics) overlaps that rect.
Translated captions expand horizontally → text overflows into adjacent image area.

Fix strategy:
1. At the start of each page's processing loop, collect bboxes of all image blocks
   (type==1 in `page.get_text("dict")["blocks"]`) into a list `image_rects`.
2. Add helper `_clip_rect_away_from_images(rect, image_rects) -> pymupdf.Rect`:
   - For each image rect, check if it intersects the text rect.
   - If an image is to the RIGHT of the text rect center and overlaps: clip the
     text rect's right edge to the image's left edge (x1 = image.x0).
   - If an image is BELOW the text rect center and overlaps: clip the text rect's
     bottom edge to the image's top edge (y1 = image.y0).
   - Return the clipped rect (or original if no overlap detected).
3. In Pass 3 (`insert_htmlbox`), apply `_clip_rect_away_from_images` before calling
   `page.insert_htmlbox`. If the resulting clipped rect is below the minimum
   dimensions, append an overflow flag (reason="image_collision") and skip insert.
4. The redaction pass (Pass 1 + Pass 2) still uses the ORIGINAL rect — we redact
   the full original bbox to erase the source text completely, then reinsert into
   the (possibly clipped) safe rect.

Purpose: Caption text no longer overflows into adjacent image bounding boxes.
Output: Updated `reassembler.py` with `_clip_rect_away_from_images`; 2 new tests.
</objective>

```python
def _clip_rect_away_from_images(
    rect: pymupdf.Rect,
    image_rects: list[pymupdf.Rect],
) -> pymupdf.Rect:
    """
    Shrink rect to avoid overlapping adjacent image blocks.

    Strategy:
    - For each image rect that intersects the text rect:
        - Image to the right: clip text rect's right edge to image's left edge
        - Image below: clip text rect's bottom edge to image's top edge
    - Returns the (possibly clipped) rect. If no overlap, returns the original rect unchanged.

    Does NOT clip left or top edges — captions typically extend right or down
    when translated text expands, not left or up.

    PPTX-analog: mirrors the auto-fit shape-height guard; same conservative principle.
    """
    clipped = pymupdf.Rect(rect)  # copy
    for img in image_rects:
        if not clipped.intersects(img):
            continue
        # Image is to the right of rect center: clip right edge
        if img.x0 > clipped.x0 and img.x0 < clipped.x1:
            clipped = pymupdf.Rect(clipped.x0, clipped.y0, img.x0, clipped.y1)
        # Image is below rect center: clip bottom edge
        if img.y0 > clipped.y0 and img.y0 < clipped.y1:
            clipped = pymupdf.Rect(clipped.x0, clipped.y0, clipped.x1, img.y0)
    return clipped
```
