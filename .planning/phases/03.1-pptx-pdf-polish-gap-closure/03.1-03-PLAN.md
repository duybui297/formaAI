<objective>
Close UAT Gap 3 (Test 7): PDF heading hierarchy lost in translation.

Root cause: `spans_to_html` in `extractor.py` only emits `<b>/<i>` based on span
flags (bold=bit4, italic=bit1). It does not detect heading levels based on font
size. When translated PDF is reassembled, all text uses the same visual weight —
`<h1>` and `<h2>` titles are indistinguishable from body text.

Fix strategy:
1. Add `_detect_heading_level(span_font_size: float, body_font_size: float) -> int`:
   - Returns 0 (body), 1 (h1), or 2 (h2)
   - H1: span font size >= body_font_size * 1.8
   - H2: span font size >= body_font_size * 1.4 and < 1.8x
   - Body: below 1.4x threshold
   - This threshold-based approach is RESEARCH.md-recommended and avoids cluster
     analysis overhead.

2. Compute `body_font_size` in `spans_to_html(block)`: find the MODE (most common)
   font size across all spans in the block, treating that as the body baseline.

3. Wrap heading spans in `<h1>...</h1>` or `<h2>...</h2>` tags in addition to
   any bold/italic wrapping. For headings, skip the `<b>` wrapper — `<h1>/<h2>`
   carry their own visual weight.

4. The CSS passed by `build_noto_archive_and_css` in `fonts.py` already controls
   font size for `insert_htmlbox`. Add heading size rules to the returned CSS:
   `h1 { font-size: 1.6em; font-weight: bold; }` and
   `h2 { font-size: 1.3em; font-weight: bold; }`.
   This ensures `<h1>/<h2>` in the translated HTML render visually larger.

5. No change to segment extraction logic — `source_text` continues to be the HTML
   from `spans_to_html`, which now may contain `<h1>/<h2>` tags. These pass through
   the translation pipeline unchanged (LLM sees them as part of the HTML). The
   reassembler already uses `insert_htmlbox` which parses HTML natively.

Purpose: Academic papers and documents with visual section titles retain heading
hierarchy in the translated PDF output.
Output: Updated `extractor.py` with `_detect_heading_level` + `body_font_size`
computation; updated `fonts.py` CSS; 3 new tests.

3. In `extractor.py`, add `_detect_heading_level` helper function before `spans_to_html`:

```python
def _detect_heading_level(span_font_size: float, body_font_size: float) -> int:
    """
    Classify a span's font size relative to the block's body font size.

    Returns:
      1 → h1 (span_font_size >= body_font_size * 1.8)
      2 → h2 (span_font_size >= body_font_size * 1.4 and < 1.8x)
      0 → body text (below 1.4x threshold)

    Threshold rationale (rule-based, avoids cluster analysis overhead):
      - Academic papers: section titles are typically 14-18pt on 10-12pt body → ratio 1.4-1.5
      - Document headings: 18-24pt on 12pt body → ratio 1.5-2.0
      - 1.4x lower bound catches most h2 cases; 1.8x upper bound separates h1 from h2
    """
    if body_font_size <= 0:
        return 0
    ratio = span_font_size / body_font_size
    if ratio >= 1.8:
        return 1
    if ratio >= 1.4:
        return 2
    return 0
```

4. Add `_body_font_size(block: dict) -> float` helper before `spans_to_html`:

```python
def _body_font_size(block: dict) -> float:
    """
    Estimate the body font size for a block by finding the mode (most common)
    font size across all spans.

    Falls back to the median if all sizes are unique, or 12.0 if block is empty.
    Rounds to 0.5pt precision to group near-identical sizes (e.g. 11.9 and 12.0).
    """
    from collections import Counter  # noqa: PLC0415
    sizes: list[float] = []
    for line in block.get("lines", []):
        for span in line.get("spans", []):
            size = span.get("size", 0.0)
            if size > 0:
                sizes.append(round(size * 2) / 2)  # round to 0.5pt
    if not sizes:
        return 12.0
    most_common = Counter(sizes).most_common(1)[0][0]
    return most_common
```

5. Modify `spans_to_html(block: dict) -> str` to use heading detection:

```python
def spans_to_html(block: dict) -> str:
    """
    Convert a page.get_text("dict") text block to minimal HTML.

    Preserves bold (<b>) and italic (<i>) from span flags.
    NEW (Gap 3): Emits <h1>/<h2> for spans whose font size is significantly
    larger than the block's body font size (via _detect_heading_level).
    Heading spans do NOT get an additional <b> wrapper — <h1>/<h2> carry bold weight.
    """
    body_pt = _body_font_size(block)
    parts: list[str] = []
    for line in block.get("lines", []):
        for span in line.get("spans", []):
            text = span.get("text", "")
            if not text:
                continue
            escaped = _html.escape(text)
            flags = span.get("flags", 0)
            is_bold = bool(flags & (2**4))
            is_italic = bool(flags & (2**1))
            span_size = span.get("size", 0.0)
            heading_level = _detect_heading_level(span_size, body_pt)

            if heading_level == 1:
                # h1: wrap in <h1>; italic still applies if set
                inner = f"<i>{escaped}</i>" if is_italic else escaped
                parts.append(f"<h1>{inner}</h1>")
            elif heading_level == 2:
                inner = f"<i>{escaped}</i>" if is_italic else escaped
                parts.append(f"<h2>{inner}</h2>")
            elif is_bold and is_italic:
                parts.append(f"<b><i>{escaped}</i></b>")
            elif is_bold:
                parts.append(f"<b>{escaped}</b>")
            elif is_italic:
                parts.append(f"<i>{escaped}</i>")
            else:
                parts.append(escaped)
        parts.append(" ")
    return "".join(parts).strip()
```
