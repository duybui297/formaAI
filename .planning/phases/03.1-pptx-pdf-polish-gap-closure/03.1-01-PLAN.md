<objective>
Close UAT Gap 1 (Test 3): PPTX layout shift on translation.

Root cause: `detect_pptx_overflow` uses a global char-ratio proxy at shape level.
38% auto-fit (76/200 segments) means auto-fit fires on even small expansions,
shrinking entire text frames to compensate for a single long paragraph. This
produces illegibly small text when a shape has multiple paragraphs of different
sizes.

Fix strategy:
1. Add `_paragraph_dominant_font_pt(paragraph) -> float` — return the maximum
   run.font.size (in pt) across all runs in a paragraph, defaulting to 18pt if
   none set. This gives the actual font budget per paragraph.
2. Compute estimated rendered lines for translated text at that font size inside
   the shape's width. If the text fits within shape height, skip auto-fit entirely.
3. Tighten the auto-fit threshold: only apply `TEXT_TO_FIT_SHAPE` when
   char_ratio is between 1.0 and 1.43 (shrink >= 0.7). This is unchanged.
4. Guard: only apply `TEXT_TO_FIT_SHAPE` when shape.height is set (> 0). Shapes
   with auto-height (height == 0) already reflow naturally — applying auto-fit
   to them forces a shrink that fights the auto-height setting.

Purpose: Reduce false-positive auto-fit from 38% toward the real overflow rate.
Output: Updated `reassembler.py` with `_paragraph_dominant_font_pt`, shape-height
guard, and new test cases.
</objective>

1. In `reassembler.py`, add helper function `_paragraph_dominant_font_pt(paragraph) -> float` immediately before `detect_pptx_overflow`:

```python
def _paragraph_dominant_font_pt(paragraph) -> float:
    """
    Return the largest font size (in points) across all runs in the paragraph.

    Falls back to 18.0pt if no run has an explicit font.size set (EMU units,
    None means "inherit from theme"). This is used to estimate whether the
    translated text fits in the shape without auto-fit.

    python-pptx: run.font.size is in EMUs (914400 EMU = 1 inch = 72pt).
    Conversion: pt = emu / 12700
    """
    max_pt = 0.0
    for run in paragraph.runs:
        size_emu = run.font.size
        if size_emu is not None and size_emu > 0:
            pt = size_emu / 12700
            if pt > max_pt:
                max_pt = pt
    return max_pt if max_pt > 0 else 18.0  # default theme font size
```

# Shape-height guard: shapes with height == 0 (auto-height) already reflow
