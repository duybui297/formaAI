# Phase 03.3 Plan 01: Table Cell Fidelity Fix Summary

**One-liner:** Inset table_cell insert rect by 1.5 pt + lower scale_low to 0.3 to fix word adhesion and blank cells in native PDF reassembler.

## What Was Built

Two targeted bug fixes in `backend/src/app/pipeline/pdf/reassembler.py` for the native PDF table_cell rendering path, diagnosed from demo job 7f958166 (1409 segments, 98% table_cell).

### Bug 1 Fixed — Word Adhesion (BUG-1-word-adhesion)

Adjacent cells share a border-centerline coordinate (`c0.x1 == c1.x0 == 150.0`). Without an inset, `insert_htmlbox` filled cell0 text right to x=150 and cell1 started at x=150, causing PDF word extraction to join them as `"đoạnGiá"`. 

**Fix:** Apply `_TABLE_CELL_INSET_PT = 1.5` pt inset to the **insert rect only**. The redact rect (Pass 1) stays at full cell dimensions to fully erase source glyphs.

### Bug 2 Fixed — Blank Cells (BUG-2-blank-cells)

`insert_htmlbox` with `scale_low=0.7` returned `spare_height=-1` and rendered **no text** for JP→VN-expanded text in 80–120 pt wide, 12–20 pt tall cells (3× expansion requires scale ~0.40–0.65).

**Fix:** Use `_TABLE_SCALE_LOW = 0.3` for `table_cell` segments only. Non-table segments retain `cell_scale_low = 0.7` (unchanged behaviour).

### Code Changes

**Constants added** (after `_MIN_RECT_WIDTH_PT = 20.0`):
```python
_TABLE_CELL_INSET_PT = 1.5
_TABLE_SCALE_LOW = 0.3
```

**Pass 3 conditional branch** (after `safe_rect = _clip_rect_away_from_images(...)`):
```python
if seg.kind == "table_cell":
    insert_rect = safe_rect + (
        _TABLE_CELL_INSET_PT, _TABLE_CELL_INSET_PT,
        -_TABLE_CELL_INSET_PT, -_TABLE_CELL_INSET_PT,
    )
    if insert_rect.is_empty or insert_rect.width < 5 or insert_rect.height < 3:
        insert_rect = safe_rect  # degenerate cell — skip inset
    cell_scale_low = _TABLE_SCALE_LOW
else:
    insert_rect = safe_rect
    cell_scale_low = 0.7
```

**Pass 1 unchanged:** `page.add_redact_annot(rect, fill=None)` — always uses full cell rect.
